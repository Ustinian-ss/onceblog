> 播放任意音乐，屏幕上 48×48 的光柱网格随频谱起伏、发光 —— 中心是低频，边缘是高频，鼓点砸下来时会有一圈脉冲扩散出去。这篇笔记记录地形映射、渲染回退和多端复用的几个决定。

<!--more-->

## 一、目标：把声音变成地形

想做的不是常见的柱状频谱条，而是一片会呼吸的「地形」：网格状排布的光柱，高度由频谱驱动，整体像水面一样起伏。核心约束有三条：

- **零框架、零依赖**，因为最终要能塞进 Wallpaper Engine 的 Web 壁纸
- 中心低频、边缘高频，让画面中心「砸」得最重
- 桌面、浏览器、手机都要能跑

## 二、三条音频输入路径

| 输入 | 用途 | 特点 |
|---|---|---|
| 系统音频 | 检测当前正在播放的音乐 | 无需导入文件，最省事 |
| 麦克风 | 环境声 / 哼唱 | 适合演示和随手玩 |
| 本地文件 | 导入音频播放（可多选连播） | 可控性最好 |

三条路径最终都汇到同一个 `AnalyserNode`，后面的分析逻辑完全复用 —— 这是整个项目里最省事的一个抽象。

## 三、从频谱到地形

`AnalyserNode` 给出一串频域数据，但直接把第 N 个频点映射到第 N 根柱子并不好看：低频段频点密、能量大，高频段稀疏、能量小，结果就是左边一根擎天柱、右边一片平。

所以做了两步处理：

1. **分带聚合**：把频谱按对数刻度划成低频 / 中频 / 高频几段，再按位置采样成 48 路驱动值
2. **节拍检测**：低频能量相对近一段时间的均值出现突增时，判定为一次鼓点，触发脉冲环扩散和地形闪烁

光柱的排布按到中心的距离决定取哪一段频率：**越靠中心越取低频，越靠边缘越取高频**。这样鼓点来了，冲击感自然集中在画面中央。

## 四、渲染：WebGL 优先 + Canvas 2D 回退

渲染层有两条实现路径：

- **WebGL**：48×48 就是 2304 个柱体，走 GPU 才能稳住帧率，尤其是在壁纸模式下长时间后台运行
- **Canvas 2D 回退**：显卡驱动异常、WebGL 上下文丢失、或者跑在性能受限的环境里时自动降级

降级不是可选项 —— 壁纸是要 7×24 挂在桌面上的，一旦渲染层崩掉，用户看到的就是一块黑屏。

## 五、材质与主题

音柱材质做了 4 种：**玻璃 / 亚克力（磨砂）/ 实心 / 发光**，每种都能单独调模糊、透明度、高光强度和柱体圆角。13 套配色主题（深海、冰蓝、极光、暖金、熔岩、血红、星云、霓虹、极简……）是预设值，参数面板里还能继续微调律动强度、响应速度、闪烁、亮度、俯视视角、色相偏移。

这里有个刻意的设计：**主题和材质是正交的**。换主题不应该动材质参数，换材质也不应该覆盖配色 —— 否则用户会陷入「调好一个、换一个就全乱」的困境。

## 六、零依赖换来的三个出口

因为渲染核心是纯 HTML + Canvas，同一套代码可以直接复用成三种形态：

1. **浏览器**：直接打开 `app/index.html`，或 `npm run serve:web` 起本地服务
2. **桌面端**：Electron 套壳，`electron-builder` 打安装版和便携版 exe
3. **壁纸**：Wallpaper Engine 新建「网页」类型壁纸，填入 `app/index.html` 路径即可，还能设置音频响应来源

另外构建脚本能把它压成**移动端单文件 HTML**，发到手机上直接打开就能用；也可以起局域网服务给同一网络的设备访问。

## 七、一些细节

- **点击 / 触摸画面**会在该处激起一圈能量光环
- **鼠标滑过**会让音域局部轻微抬升（可关闭，否则长时间用会觉得吵）
- **设置记忆**：主题、参数、提示文字状态自动保存，刷新不丢
